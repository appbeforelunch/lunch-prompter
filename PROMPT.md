Build a teleprompter web app that does the job people pay $9.99 a month for in teleprompter apps: read a script on screen while recording a video.

- Scripts: write or paste a script, give it a title, keep several, and keep them saved in this browser between visits.
- Prompter: full-screen, large readable text that scrolls smoothly on its own. Speed control in words per minute, play and pause with the space bar and with an on-screen button, arrow keys to nudge, a 3-2-1 countdown before it starts, mirror mode (flipped left to right), adjustable text size and margins, a reading line, and an estimated read time at the chosen speed.
- Record: optional camera recording with the script on screen, saved as a video file the user downloads. No watermark and no time limit. Nothing is uploaded. If camera access is denied, say so and keep the prompter working.
- Not included: no voice-following scroll, no accounts, no cloud sync.
- Plain HTML, CSS and JavaScript in this folder. No build step, no packages, no network calls, no external fonts or CDNs. It must work offline by opening index.html in Chrome, on a laptop or a phone browser.
- Give it its own name. Do not use the name or logo of any existing teleprompter app.
- Include one short sample script about making toast, written fresh, with no real names or places.
- Write automated tests for it, run them in the foreground, and wait for them.
- README: what it does, how to open it, and a short "What it can't do" section compared with paid teleprompter apps.
